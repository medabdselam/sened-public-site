Privacy Policy

Last updated: 27 September 2026

This page explains how the Sened for Restaurants application handles restaurant data, in particular when the optional Google Drive backup is enabled. It applies to the desktop application and to this website.

On this page

  • Restaurant data
  • Google Drive — access and use
  • Storage and sharing
  • Control and deletion
  • Diagnostics and this website
  • Contact and updates

Restaurant data

Sened records orders, products, inventory, expenses, settings and staff accounts in a database on the restaurant's own device. Waiter and kitchen devices may reach this data over the local network the owner sets up. The owner controls the device, staff permissions and backups.

There is no server of ours to which restaurant data is sent; we do not look at it, do not sell it, and do not share it with advertisers.

Google Drive — access and use

Sened does not ask to link Google Drive unless the owner chooses to. The application uses the https://www.googleapis.com/auth/drive.file scope to create Sened's own backup folder and files in the Google account the user links, then to find and list those backups and download a selected one in order to restore the database.

A backup may contain all restaurant data, including orders, customers, settings and user accounts. Sened does not use this scope to read Drive files unrelated to the application, does not use Google user data for advertising, does not transfer it to others, and does not use it to train models.

Storage and sharing

The primary database stays on the restaurant's device. When Drive backup is enabled, a copy is transferred to the owner's Google account and is then also subject to Google's policies. Sened keeps the connection token on the device using protected storage provided by the operating system; this website never displays restaurant data or access tokens.

Control and deletion

The owner can disconnect Google Drive from Sened's settings to stop future access, or revoke access from the Google account permissions page. Disconnecting does not automatically delete backup files already created; they can be managed or deleted in Google Drive.

The owner can select a backup to restore inside the application, taking a local safety copy before replacement. To delete data from the restaurant's device, the owner manages the database and local backups directly. For any privacy question or request, write to the support address below.

Diagnostics and this website

This edition of Sened does not send usage telemetry to the original vendor. This public site is hosted by GitHub Pages, which may process visit data under the GitHub Privacy Statement. Our pages contain no trackers, no cookies of ours and no data-collection forms, and run no JavaScript; fonts are loaded from Google Fonts. Technical details are on the Security page.

Contact and updates

For questions or privacy requests, write to support@sened.group. We will update this page if the way Sened handles data changes; the date of the last update is shown at the top.
